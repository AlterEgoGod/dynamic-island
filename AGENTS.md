# Требования проекта

- Это нативный виджет Windows в стиле Dynamic Island, закреплённый у края рабочего стола.
- Единая методология дизайна: [docs/DESIGN.md](docs/DESIGN.md). Следовать ей при любых изменениях интерфейса; токены цветов находятся в `src/Design.cs`, стили компонентов — в `src/Panel.xaml`.
- Основное поведение: в скрытом состоянии видна небольшая полоса; наведение мыши раскрывает панель, уход курсора сворачивает её.
- Оформление ориентировано на iconly.pro. Использовать настоящие иконки Iconly Light / Regular; SVG, идентификаторы и контрольные суммы находятся в `assets/iconly/`. Значок трея тоже использует Iconly.
- Панель переносится мышью только за верхнюю ручку, а в свёрнутом состоянии — за узкую полосу и приклеивается к ближайшему краю монитора. Тумблер «Выровнять по центру» центрирует её вдоль края при переносе. Сохранять край, монитор, положение, центрирование и поддержку DPI. Esc во время переноса отменяет его. Выбор края/монитора и тумблер закрепления в настройках не показывать.
- Заголовок: `Dynamic Island`; подпись кнопки калькулятора: `Калькулятор`.
- Изначально время таймера не задано (плейсхолдер «—:—»). Редактируется прямо в цифрах: минуты или мин:сек, Enter применяет, Esc отменяет, очистка возвращает пустое состояние. Ограничение в 180 минут не вводить; длинные значения должны помещаться и безопасно сохраняться без переполнения. Поле добавления шаблона пустое, очищается после добавления. Шаблоны по умолчанию: 5, 10, 15, 30, 60 и 90 минут. Отдельное поле времени и OK не показывать. Удаление шаблона и просмотр времени без изменения не прерывают отсчёт. Рядом независимый секундомер. Звук завершения — 3,3 секунды.
- В настройках есть «Сбросить все настройки»: восстановить все значения виджета по умолчанию, остановить оба отсчёта и сохранить результат; авторизацию ChatGPT не сбрасывать. В трее только открытие, настройки и выход, без выбора края.
- Вход Codex доступен через кнопку «Войти через браузер» с состоянием входа. Codex определяется автоматически; ручной выбор файла в интерфейсе не показывать.
- Лимиты Codex показывать по принципу TokenStats: остаток квоты, пятичасовой и недельный периоды, даты сброса и обновление каждые 30 секунд через официальный app-server. Отсутствующие данные не подменять нулём или другой квотой.
- Анимация раскрытия должна оставаться плавной, с постепенным появлением содержимого и учётом системного отключения анимаций.
- Сохранять неподвижное прозрачное окно при наведении: полоса и панель меняются внутри него, невидимая область пропускает клики. Контент явно обрезается текущим размером панели. Задержка скрытия — 0–1500 мс.
- Стандартная задержка — 200 мс, центрирование включено. Не скрывать панель во время активного ввода. Карточки таймеров и их кнопки выровнены; шаблоны в настройках — три колонки; сброс и выход закреплены вне прокрутки.
- Контраст основного, вторичного и акцентного текста в обеих темах — не ниже 4,5:1. Иконка приложения в заголовке и трее — Iconly Category (`brand.svg`).
- Не включать API-ключи в исходники или сборку. Для загрузчика использовать `ICONLY_API_KEY` из окружения процесса.

# Разработка

- Музыкальная карточка управляет проигрывателями Windows. Кнопка сервиса/библиотеки и выбор трёх сервисов удалены из пользовательского интерфейса; музыку пользователь запускает в браузере или приложении. Cookies браузера не читать и не переносить.
- Windows 10 1809+; меню «Источник» содержит «Автоматический выбор» по умолчанию и реальные медиасессии с приложением и треком. Автоматический режим следует текущему источнику Windows, ручной не переключается при закрытии выбранной сессии. Повторный выбор автоматического режима сразу возвращает актуальный источник. Обложка, альбом, перемотка, повтор и случайный порядок отражают реальные метаданные и возможности. Громкость через Core Audio относится ко всему приложению (для браузера — ко всем вкладкам), не к системному выходу. Не управлять реальной музыкой и громкостью пользователя в тестах.
- Прежний WebView2-экран сохранён в исходниках для совместимости и внутренних проверок, но не открывается из пользовательского интерфейса. Не возвращать выбор музыкальных сервисов без нового запроса пользователя. Windows SDK Contracts закреплён по SHA-256 в tools/restore-media-sdk.ps1. --media-test проверяет API без команд и без сохранения названий треков.

- Карточка таймера — полноценный таймер: запуск/пауза/продолжение/повтор, прогресс, время окончания, «Заново» и «+1 мин». Допускается ввод ч:мин:сек. Сброс таймера находится в самой карточке, не в настройках.
- Быстрый доступ управляется в настройках: добавление EXE и ярлыков, переименование, удаление; хранить список в preferences. Не запускать программы в тестах и не удалять их с диска при удалении из списка. Иконка пользовательского приложения — Iconly Category, системных действий — прежние Iconly.
- Музыка встроена через WebView2CompositionControl, совместимый с прозрачным WPF-окном. Официальные страницы Яндекс Музыки, Spotify, YouTube Music; вход на стороне сервиса, без копирования токенов и без обхода ограничений Google/DRM. Подписывать ограничения и предоставлять открытие в браузере. Cookies хранятся в отдельном WebView2-профиле и сохраняются при сбросе настроек.
- В музыкальном экране доступно расширение до 960 × 780 DIP в пределах экрана; при скрытии сохранять неподвижный нативный canvas и узкую полосу. Возврат к виджету и скрытие не уничтожают плеер; смена сервиса, сброс и выход прекращают прежний поток. Не перехватывать перетаскивание внутри WebView2. Ввод и отдельное окно входа удерживают панель открытой.
- WebView2 SDK закреплён по версии и SHA-256 в tools/restore-webview2.ps1. Распространять всю dist вместе с библиотеками и лицензиями. Проверку --music-test выполнять с изолированным профилем; --music-probe — отдельная сетевая проверка публичных страниц, без аккаунтов.

- Стек: WPF, .NET Framework 4.8, C# 5; сборка встроенным `csc.exe`, без npm и .NET SDK.
- Основные файлы: `src/Panel.xaml`, `src/DynamicIsland.cs`, `src/Design.cs` и `src/widgets/codex/CodexLimits.cs`.
- Сборка: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1`.
- После изменения поведения запускать `dist/DynamicIsland.exe --self-test` и `--smoke-test`, проверяя коды возврата и отчёты в `artifacts/`.
- Проверки не должны менять пользовательские настройки, перемещать курсор или открывать внешние приложения.

# Модульная архитектура

- Каждый блок — отдельный встроенный `IIslandWidget`, папка `src/widgets/<id>/` содержит Widget.cs, View.xaml, Settings.xaml и контроллеры. Общий контракт и хранилище — src/WidgetModules.cs, контейнер и управление — src/WidgetHost.cs. Сборка рекурсивно включает исходники и ресурсы.
- В настройках доступны тумблеры и параметры модулей, без управления порядком. Порядок и включение сохраняются; таймер и секундомер находятся в общем модуле «Время». Нельзя терять состояние при перестановке. Отключение ставит таймеры на паузу и останавливает опрос музыки/Codex, не внешнее воспроизведение. Все модули можно отключить, доступ к настройкам остаётся.
- Настройки оболочки и порядок: %LOCALAPPDATA%/DynamicIsland/settings.xml. Параметры каждого виджета и enabled: widgets/<id>/settings.xml рядом с общим файлом. В рабочем приложении использовать WidgetSettingsStore; Preferences.Load/Save остаются кодеком старого формата для миграции и проверок. Первая миграция сохраняет settings.xml.legacy.bak. У каждого файла атомарная запись, отдельные модули не стирают настройки друг друга.
- Это архитектура встроенных модулей одного процесса, с общим адаптером partial Island для прежних контроллеров. Не обещать загрузку внешних DLL или отдельные микросервисы. Добавлять новые блоки через реестр WidgetCatalog; не возвращать жёсткую разметку главного экрана в Panel.xaml.
- Главный экран редактируется через Iconly Edit в заголовке: показывать тумблер и оригинальные стрелки Iconly вверх/вниз, в том числе для выключенных виджетов. Esc завершает редактирование; авто-сворачивание редактора отключено. Изменение порядка доступно только в редакторе главного экрана.
- «Время» (`time`) объединяет таймер и секундомер. Перемещать и выключать их вместе; при выключении ставить оба на паузу. Миграция читает прежние focus/stopwatch и не теряет длительность, шаблоны или порядок. Пользовательское имя «Фокус» больше не использовать.
- Перенос острова разрешён только за верхнюю ручку или свёрнутую полосу, никогда за заголовок или карточки.
- Next/previous проверять только на изолированной тестовой медиасессии через --media-command-test. Возможности текущего источника читать перед командой, не заменять адресата и не повторять команды вслепую. Сообщать об отсутствии поддержки у источника, не обещать переключение, которое он не предоставляет.
- Меню источников использует стили SourceMenu/SourceMenuItem, общие цветовые токены и оригинальные Iconly. Обновлять открытое меню при изменении медиасессий. Не скрывать источник при пустом названии трека или ошибке метаданных. Имя брать из Windows AppInfo с совместимым резервным определением; неизвестные приложения не называть Windows Media Player. Не показывать установленные приложения как активные сессии.

- Совместимость музыки: GSMTC + отдельный WmpRemote для уже запущенного классического WMP + обнаружение Core Audio. Резервные аудиоисточники предоставляют только громкость, без выдуманных метаданных и состояния транспорта. Объединять дубликаты приложения; не переключать команды на другой процесс. Не отправлять глобальные медиаклавиши или WM_APPCOMMAND. Требования к адаптеру и ползункам — в разделе «Совместимость музыкальных источников» docs/DESIGN.md.
- Обработчик нажатия музыкального Slider обязательно получает уже обработанные WPF события (handledEventsToo), иначе обычный клик не отправляет значение. Проверять одиночный клик, удержание значения при опросе и отмену при смене трека без управления реальной музыкой.
- Быстрый доступ поддерживает веб-ссылки HTTP/HTTPS через встроенное поле в настройках; Enter добавляет, Escape очищает ввод. Без схемы добавлять HTTPS. Хранить адрес целиком в модуле quick-access, не изменять регистр пути. Иконка ссылки — оригинальный Iconly Home / 405. Не открывать сайты в автотестах. Подробности — раздел «Ссылки быстрого доступа и верхняя ручка» docs/DESIGN.md.
